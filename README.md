# Credit Risk Intelligence

Desenvolver uma plataforma avançada de análise e previsão de risco de crédito para instituições financeiras.

O sistema deverá utilizar Python, Pandas, PostgreSQL, Scikit-learn e Power BI, incluindo coleta e tratamento de dados financeiros reais ou públicos, análise exploratória, identificação de padrões de inadimplência, criação e avaliação de modelos preditivos de machine learning e simulação do impacto de diferentes políticas de concessão de crédito.

O projeto deverá seguir boas práticas de engenharia de software, incluindo arquitetura modular, documentação profissional, testes automatizados, versionamento com Git e visualizações interativas.

A inteligência artificial deverá dividir o desenvolvimento em pequenas tarefas diárias, informando as tecnologias utilizadas, a dificuldade, o tempo estimado e os critérios de conclusão de cada etapa.

A cada execução, a IA deverá implementar uma nova funcionalidade, validar o código, preservar o trabalho anterior e realizar um commit incremental no GitHub.

O objetivo final é construir um projeto avançado de portfólio, demonstrando conhecimentos de Análise de Dados, SQL, Python, estatística, machine learning e aplicações práticas no setor bancário.

Projeto iniciado com DevFlow AI.
